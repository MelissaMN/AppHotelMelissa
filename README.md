# Serena Hotel — AppHotelMelissa (.NET MAUI para Windows)

Projeto .NET MAUI preservado e configurado para compilar somente para Windows.

## Requisitos
- Windows 10 versão 1809 (build 17763) ou superior
- Visual Studio 2022 com a carga de trabalho **Desenvolvimento da interface do usuário de aplicativos multiplataforma .NET**
- .NET 8 SDK e componentes do Windows App SDK instalados pelo Visual Studio

## Abrir e executar
1. Extraia a pasta `AppHotelMelissa`.
2. Abra `AppHotelMelissa.csproj` no Visual Studio.
3. Na barra superior, selecione `Windows Machine`.
4. Pressione F5.

O projeto foi limitado ao destino Windows. O código de inicialização MAUI para Windows está em `Platforms/Windows`.
